# torch uses its CPU-only build (the +cpu local version). That wheel only exists
# on PyTorch's CPU index, so I declare it here as an extra index. A plain
# `pip install -r requirements.txt` then resolves torch from it and everything
# else from PyPI, and never pulls the heavy CUDA wheel. This file is the single
# source of truth for the torch pin (the Dockerfile just installs this file).
# For a GPU build, drop the line below and the +cpu suffix on torch.
--extra-index-url https://download.pytorch.org/whl/cpu
